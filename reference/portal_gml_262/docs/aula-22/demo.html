Como interpretar esta demonstração

Cálculos pequenos e cenários didáticos executados no navegador. Não há chamadas a modelos externos. Os exemplos não representam resultados de benchmarks ou desempenho de sistemas reais. Quando uma etapa isola um mecanismo, seus números não equivalem a um modelo completo treinado.

Use as setas ← e → para navegar fora dos campos de edição. O botão Restaurar controles recupera os valores iniciais da aula. Os números exibidos são arredondados.
